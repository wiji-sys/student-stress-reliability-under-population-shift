# GitHub Upload Checklist

1. Create a new GitHub repository, e.g. `student-stress-reliability-under-population-shift`.
2. Upload the **contents** of this folder, not the ZIP itself.
3. Do **not** upload the source CSV; `.gitignore` excludes `data/*.csv`.
4. Replace the placeholder `repository-code` URL in `CITATION.cff` after the repository is created.
5. Check the rendered `README.md` on GitHub.
6. Optionally create a GitHub Release `v1.0.0` and attach the FULL ZIP as a release asset.
7. If a journal requests an immutable archive, connect the GitHub repository to Zenodo and create a DOI after the final code freeze.
